# GH-repo

### GitHub Repository extractor

What is best ways to fetch all the data of any github profile.
With all the data and an external libraries.

#### Features:
- Fast/Simple/Easy. 
- Extract data of any *github* profile.
- Get markdown file of that profile.
- Get all the repository of all the profile with the external libraries.


---
#### Just run this cmd in project terminal
```bash
pip install -r requirement.txt 
```
